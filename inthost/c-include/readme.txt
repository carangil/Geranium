./generate will:
	process some of the h files in this directory to 'tags' files using ctags
	reads information from the tags file to make .inc files for the interpreter and put in ../inc


	glfw3 has a lot of callbacks, so the types of the callbacks are put in callbacks.h to look like functions. they are then processed and added as types for processing glfw3.h

not everything in ../inc is autogenerated, so don't just delete it
